# Vision & Theory

## Product Vision
PostMaker aims to become the complete AI-powered content operating system for
creators, businesses, and agencies — moving beyond AI caption generation into an
end-to-end workflow covering creation, management, scheduling, publishing, and
analytics.

## Mission
Enable anyone to create, manage, schedule, publish, and optimize professional
content from one platform.

## Long-Term Goals
- Serve thousands of active users and agencies.
- Provide a stable, production-ready platform.
- Support complete content workflows, not just generation.
- Become the preferred platform for content creation and distribution.

## Product Principles
- Launch early.
- Iterate quickly.
- Keep workflows simple.
- Optimize for creators first.
- Build scalable architecture from day one.

## Current State (as of source docs)
- Core product is functional but requires polish.
- Existing capabilities: AI caption generation, multi-platform content
  generation, ZIP export.
- Several production features remain incomplete.
- International payment support is still pending.

## Why this task structure exists
Every task file in `phases/` traces back to either the Product Vision & Roadmap
doc or the PRD. Phases follow the roadmap's own phase order so execution matches
strategy — nothing here invents new scope.
